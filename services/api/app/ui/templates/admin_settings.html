Export API — свежесть для VPS cron

Дефолтный фильтр по content_generated_at (дата последнего AI-рерайта). Применяется, если VPS вызывает GET /integrations/theunum/v1/drafts?consumed=false без freshness, max_age_hours и generated_since. Явные query-параметры всегда важнее.

Ключи в БД: integration.export.default_freshness, integration.export.default_max_age_hours. Эндпоинт /drafts/today всегда «сегодня», независимо от этих настроек.
