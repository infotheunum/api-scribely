Окно генерации статей

Темп и свежесть (чтобы не сжечь квоту утром)

target_per_hour — сколько черновиков максимум за час (при лимите 150 и окне 12 ч бери ~12–13). max_item_age_hours — не брать в рерайт сюжеты старше N часов (отсекает ночной хвост, днём остаются более актуальные).

Ключи: dispatch.target_per_hour, ingestion.max_item_age_hours.

Ручная генерация (burst)

Ручная генерация обходит суточный лимит: сколько укажешь — столько ещё сделает поверх уже созданных сегодня (выходные 25 утром + «Сгенерировать 25» = ещё 25). Воркер снова включает poll/cluster/dispatch, пока не доберёт квоту burst или не истечёт TTL.

Языки генерации рерайта

На каких языках Rewrite Orchestrator пишет статьи. Сейчас по умолчанию только RU; позже можно включить несколько. Ключ БД: rewrite.output_locales (JSON-массив).

REST: GET/PUT /admin/rewrite/output-locales (JWT admin). Если ничего не отмечено — сохранится ["ru"].

LLM-провайдеры (ротация новостей)

Какие слоты участвуют в enrich / rewrite / confirm-duplicate. Round-robin и failover только среди отмеченных (и только если ключ есть в env rewrite). По умолчанию — только OpenAI. Ключ БД: llm.enabled_providers.

REST: GET/PUT /admin/llm/enabled-providers. Если ничего не отмечено — сохранится ["openai"]. OpenRouter в ротацию статей не входит.

Дедуп: LLM-confirm

Сверка borderline-матчей через ConfirmDuplicate. Баланс по умолчанию: включено, порог 0.85, макс. 1 кандидат (раньше было 0.45×3 и съедало почти весь бюджет OpenAI). Merge без LLM только при cosine ≥ 0.98.

Ключи: dedup.llm_confirm_enabled, dedup.confirmation_threshold, dedup.max_confirmation_candidates.

Ревью: перевод оригиналов

Добавляет к новым черновикам полный русский перевод исходных материалов. Он сохраняется в карточке вместе с фактологической сверкой; отключение не удаляет уже созданные переводы.

Export API — свежесть для VPS cron

Дефолтный фильтр по created_at (дата создания черновика). Применяется, если VPS вызывает GET /integrations/theunum/v1/drafts?consumed=false без freshness, max_age_hours и generated_since. Явные query-параметры всегда важнее.

REST для внешней админки: GET/PUT /admin/integration/export-settings (JWT admin). Схема всех фильтров для cron: GET /integrations/theunum/v1/export-schema (integration token).

Ключи в БД: integration.export.default_freshness, integration.export.default_max_age_hours, integration.export.default_limit. Эндпоинт /drafts/today всегда «сегодня», независимо от этих настроек.
