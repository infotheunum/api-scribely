# Правила рерайта и стиля новостей — UNUM Rewriter Tool

**Статус:** v0.1 — зафиксировано как базовая версия для реализации (2026-07-31); допущение по объёму текста (§5) уточняется по ходу разработки
**Проект:** UNUM_news_100
**Назначение:** конкретный стайл-гайд, который ложится в основу системного
промпта для **Rewrite Orchestrator** (см. [ТЗ_Rewriter_Tool_Черновик.md](ТЗ_Rewriter_Tool_Черновик.md),
§4.4–§4.5) и служит чек-листом для Rewriter-а при ручном ревью черновика.

> Обозначение в тексте: **[П]** — правило, заданное пользователем напрямую;
> без пометки — дополнено мной как редактором, исходя из цели «пользователю
> легко, удобно и интересно читать».

---

## 1. Область действия

- Оба языка публикуются на сайт: **английский** (основной рерайт) и
  **русский** (перевод) — оба должны соответствовать этим правилам, кроме
  пункта 3 (орфография/обороты), который специфичен для русского языка.
- Правила применяются на этапе генерации (промпт рерайта/перевода) и
  дополнительно проверяются автоматическим Policy/Compliance Checker
  (ТЗ §4.6) перед попаданием черновика в очередь ревью.

## 2. Заголовок

**[П]** Простой заголовок — по правилам Дзена (https://dzen.ru/about/news).

Конкретные критерии из правил Дзена (проверено 2026-07-31,
[content_requirements.html#headers_quality](https://dzen.ru/help/ru/requirements/content_requirements.html#headers_quality)):

- Без кликбейта: не искажать смысл ради привлечения внимания, не
  гиперболизировать, не оставлять интригу вместо сути.
- Без метафор и речевых штампов («гвоздь программы», «вишенка на торте» и
  подобных).
- Без жаргона и разговорных выражений.
- Без оценочных суждений — нейтрально и фактологично (перекликается с §2.3
  редполитики UNUM — беспристрастность).
- Все цитируемые в заголовке высказывания — с атрибуцией; никаких
  обобщённых источников («эксперты считают», «СМИ сообщают») — только
  конкретное имя, должность, издание.
- Естественный порядок слов, без инверсий ради красоты.
- Заголовок сразу называет главное событие, а не намекает на него
  («заголовки-открывашки» запрещены).
- Заголовок грамматически безупречен и точно отражает содержание текста, без
  преувеличения (см. также §6.3.5 редполитики UNUM).

Дополнительно (мои правила редактора — для читабельности и CTR без
кликбейта):

- Ориентировочная длина — 50–90 символов (комфортно для мобильных превью,
  соцсетей и поисковой выдачи); длиннее — только если короче теряется суть.
- Заголовок начинается с самого важного слова/субъекта события, а не с
  вводных конструкций («Стало известно, что…», «Как сообщается…»).
- Без ЗАГЛАВНЫХ БУКВ для акцента; без восклицательных знаков (в крайнем
  случае — не больше одного).
- Первое предложение текста (лид) не повторяет заголовок дословно — оно
  раскрывает его новой информацией.

## 3. Орфография и обороты речи (специфично для русской версии)

**[П]** Не использовать букву «ё» — писать «е» везде.
**[П]** Не использовать связку «Таким образом» — заменять на «Так,».

Дополнительно (мои правила редактора):

- Избегать канцеляризмов и штампов: «имеет место быть» — убрать; «на
  сегодняшний день» / «в настоящее время» → «сейчас»; «следует отметить,
  что» — убрать; «данный/данная» → «этот/эта», где это естественно.
- Избегать типичных ИИ-штампов и слов-паразитов: «важно отметить, что»,
  «стоит подчеркнуть», «нельзя не сказать», «подводя итог», «в заключение».
- Не злоупотреблять тире (—) как универсальной связкой мыслей — использовать
  обычную пунктуацию и союзы.
- Не начинать несколько предложений подряд одинаковой синтаксической
  конструкцией — однообразный ритм читается как машинный текст.
- Оценочные усилительные слова без цифр под запретом: «колоссальный»,
  «беспрецедентный», «ошеломляющий», «поразительный» — вместо них факты и
  цифры.
- Не хеджировать без необходимости («возможно», «вероятно», «как
  сообщается») — если факт подтверждён, пишем прямо; если нет — это явно
  атрибутируется источнику (см. §5.2 редполитики), а не размывается
  наречиями.

## 4. Атрибуция и упоминание источников в тексте

**[П]** Ссылаться на редакторов, журналы, писать их названия в тексте.

Дополнительно (мои правила редактора):

- В самом тексте (не только в ссылке/подвале) минимум один раз называется
  издание-источник: «как сообщает Cointelegraph», «по данным Reuters»,
  «пишет The Block».
- Если материал собран из нескольких источников (кросс-языковой кластер,
  ТЗ §4.2) — называются все существенные источники, а не только первый
  попавшийся.
- Прямые цитаты — дословные, в кавычках, с указанием конкретного человека и
  его должности/роли («директор по коммуникациям Binance», а не просто
  «представитель компании»).
- Никаких анонимных/обобщённых атрибуций вида «по слухам», «источники
  сообщают» в рутинном рерайте — работа с анонимными источниками отдельно
  регламентирована §2.4 редполитики и не относится к этому потоку.

## 5. Структура и объём текста

**[П]** 3 абзаца; **каждая языковая версия** (`body_en`, `body_ru`) — цель
**2000–2300 символов с пробелами**; hard-gate пайплайна **1300–2500**
(ниже 1300 / выше 2500 → regenerate).

> Ранее допускалась неоднозначная формулировка «~2000 суммарно на оба языка» —
> **исправлено 2026-09-01**: лимит **на каждый язык отдельно**, не делится между EN и RU.
> **2026-09-02**: нижняя граница поднята с 1800 до **2000** символов (цель).
> **2026-09-03**: hard-gate снижен до **1300** (цель остаётся 2000–2300) — иначе
> free/mini-модели стабильно жгли 2–3 LLM-вызова на кластер из-за first-pass ~1400–1700.

- **Абзац 1 (лид)** — принцип перевёрнутой пирамиды (§6.3.6/§7.3
  редполитики): кто, что, когда, почему это важно — сразу, без предисловий.
- **Абзац 2** — контекст, ключевые цифры/детали, атрибуция источников.
- **Абзац 3** — значимость, реакция сторон, что дальше (если применимо; для
  чисто фактологичных новостей без развития — необязателен).
- Один факт/одна мысль на абзац — не смешивать несколько независимых фактов
  в одном абзаце.

## 6. Стиль и тон (для лёгкого и интересного чтения)

Дополнительно (мои правила редактора — цель: легко, удобно, интересно):

- Активный залог вместо пассивного, где это естественно («биржа
  приостановила торги», а не «торги были приостановлены биржей»).
- Короткие предложения; избегать многоступенчатых придаточных длиннее одной
  строки.
- Разнообразие длины и структуры предложений — монотонный ритм скучен и
  читается как машинный текст.
- Сложные термины поясняются коротко при первом упоминании (в скобках или
  придаточным), без отдельного глоссария — глоссарий предусмотрен только для
  образовательных материалов (§4.3 редполитики), не для рерайта новостей.
- Аббревиатуры расшифровываются при первом употреблении.
- Числа и суммы — с единицами и, где возможно, с сопоставлением (было/стало,
  % изменения), а не голые цифры без контекста.
- Никаких эмодзи и минимум восклицательных знаков в основном тексте.
- Перечисления из более чем 3 пунктов оформляются списком, а не одним
  длинным абзацем.

---

## 7. Связь с автоматическими проверками

- Эти правила действуют на этапе генерации черновика (промпт Rewrite
  Orchestrator, ТЗ §4.4–§4.5) и дополнительно проверяются Policy/Compliance
  Checker (ТЗ §4.6) перед тем, как черновик попадёт в очередь ревью.
- Маркировки (пресс-релиз/спонсорский контент/инвест-дисклеймер, §4.7–§4.8
  редполитики) не входят в лимит по абзацам/символам — оформляются отдельным
  блоком до или после основного текста.
